# Pejava apps for Homebrew

| App | Install |
|---|---|
| [PejavaCommander](https://pejava.com) — two-panel file manager where everything is a plugin (macOS, Linux, Windows) | `brew install --cask voy22/tap/pejava-commander` |
| [PejavaDock](https://dock.pejava.com) — alternative Dock for macOS 14+: many docks on any edge of any display | `brew install --cask voy22/tap/pejava-dock` |

Update: `brew upgrade --cask <name>`. Remove: `brew uninstall --cask <name>`
(add `--zap` to also delete settings).

Issues and questions:
- PejavaCommander: https://github.com/voy22/pejava-commander/issues
- PejavaDock: https://github.com/voy22/pejava-dock/issues
