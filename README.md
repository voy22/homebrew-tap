# PejavaCommander for Homebrew

```sh
brew install --cask voy22/tap/pejava-commander
```

Update: `brew upgrade --cask pejava-commander`. Remove: `brew uninstall --cask pejava-commander`
(add `--zap` to also delete settings and installed plugins).

PejavaCommander is a two-panel file manager for macOS, Linux and Windows: https://pejava.com

Issues and questions: https://github.com/voy22/pejava-commander/issues
